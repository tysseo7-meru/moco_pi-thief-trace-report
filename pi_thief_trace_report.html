要約

8,132件の疑惑アドレスは8,126件の巨大グループをなし、6,365件が相互送金の中核を形成した。オープン化後は約2億9,537万Piが主に取引所へ流出し、残りは3件の小グループと単独3件だった。

  • 疑惑リスト 8,132 件は、リスト内送金でたどると 8,126 件の巨大グループ、3件の小グループ、独立 3 件に分かれた。
  • 方向付きでは、相互送金の強連結コアは 6,365 件。入口は少なく（送り出し専用 41 件）、末端の受け取り専用は 1,503 件あった。
  • Open Network 開始（2025-02-20）以降、リスト内から外へ 295,373,814 Pi が流出。最大の到達点は取引所ウォレットで、OKX に 103,624,335 Pi（送金元 2,792 件）が集まった。
  • 外部流出した多くのPiは、少数の大口の送り手から取引所へ向かい、その先の大口の受け取り先でもおおむね通過していった。外へ出ていない分は少なくとも約64万 Piだった。

対象リストについて

本レポートが対象とする疑惑アドレスリストは findsp2.l_spam.txt（8,132件）である。このリストは、リスト作成者が当時のプログラムで抽出した「芯」のアドレス（278件）から、大きな送金（999 Pi 超）の宛先を2段たどって広げたものである。芯の抽出条件や広げ方の詳しい手順は、作成時のプログラムと当時の出力ファイルで確認した内容を付録に記録した（付録：対象リストの作成方法（作成時のプログラムによる確認））。

結果3：ハブへの流入の検証（被害者からの送金）

リスト作成の考え方では、抜き取り型の送金は、リスト外の被害者アドレスからリスト内のアドレスへの送金として現れる。そこで、リスト内の2大ハブである pi chain mall（GDGVILYX4RATPIO6XTBXNIBEUZXI3EBI36NJXKGO4DVJINYJ5X42WXHF）と teltlk（GBU7PR3VSIWZGQZYOHP6KEUEBJPX4HYN6FMHDB5VQNJ2NNVCWU4D5ANE）について、リスト外の送り元全員にリスト作成者の元の3条件をそのまま適用し、ドレイン型の流入が実在するかを検証した。両ハブの全履歴を取得し（HTTP 429 なし、エラー 0、上限到達なし）、リスト外の送り元は重複を除いて 21,141 件、全件を走査した。

位置づけの区別（重要）：この検証で条件に一致した送り元は、資金を抜き取られた側とみられる被害者候補であり、本レポートの対象である疑惑アドレス 8,132 件（抜き取りの受け取り側）とは正反対の立場である。疑惑リストへの追加ではないし、一致したアドレスを疑惑アドレスとして扱うものでもない。

方法：effects によるロック解除時刻の特定と残高の再構成

  • ロック解除時刻は payments からは取得できないため、effects を使った。type_i: 51（claimable_balance_claimant_created）の述語 rel_before（秒）から、解除時刻 = effect の作成時刻 + rel_before 秒 と算出する。この解釈は、同一 balance_id に対する請求（type_i: 52）が、検証した全件で算出した解除時刻以降に発生していたことで裏付けた。
  • 条件は元の3条件そのもの：(a) そのアドレスに受け取り履歴（入金記録）が一度もない、(b) 初回送金がロック解除から3分未満、(c) 送金後の残高が 2 Pi 未満。
  • 送金後残高は effects を台帳順に積算し、取引手数料を差し引いて再構成した。再構成できないものは「不明」として推測しない設計で、条件(b)の通過者については全員の残高が確定した（不明 0 件）。

条件は (a)→(b)→(c) の順に段階的に重ねて適用し、すべてを満たした送り元を (d) フルマッチとする。

この検証の限界

  • 本検証は全期間・全リスト外送り元を対象とした。これに対し元のリスト作成は、2023年の特定期間と「1,000 Pi 以上を送金したスパム候補」という別の入口条件で抽出している。期間も入口も異なるため、本結果は元のリスト作成を直接否定するものでも肯定するものでもない。特に pi chain mall のフルマッチは 2025 年以降に寄っており、元の2023年の抽出とは位相が違う。
  • 「販売代金ではない」という主張の根拠として使う場合も、この全期間スキャンではハブへの直接のドレインは量的に小さい、という留保が必要である。
  • 特に pi chain mall は実際に Pi で商品を販売しており、送り元が非常に多いため、一致した送金の中には、利用者本人がロック解除の直後に買い物の代金を払ったものが偶然混ざっている可能性がある。6件全てが被害者の送金だったとは断定できない。
  • これはリスト内の送り元に対するドレイン型チェック（複合指標で両ハブとも 0%）とは別の区間の送金の結果であり、混同しないこと。
  • チェーン上の資金移動は関与の可能性を示すだけで、人物の特定や盗みの断定にはならない。

付録：対象リストの作成方法（作成時のプログラムによる確認）

本文「対象リストについて」では概要のみを述べた。2026年11月、リスト作成時のプログラムと当時の出力ファイルを確認できたため、プログラムのコードとファイルの内容から裏付けられた作成方法を、ここに記録する。

  1. 芯の抽出（sa2405.txt）：作成者のプログラム（v3.05）を2023年10月から2024年2月まで月ごとに実行し、100 Pi以上の送金をしたアドレスを調べた。送金後の残高が2 Pi未満で、そのアドレスへの入金記録がない送金を集め、さらに、ロック解除（本人が選んだロック期間の解除と、移行の際の2週間の保留期間の解除の両方）から3分以内に行われた送金を抽出した。結果は sa2405.txt に保存された（485行、重複を除くと278アドレス）。
  2. 広がり（findsp2.py）：sa2405.txt を入力として、各種アドレスから999 Piを超える送金の宛先を集め（1段目）、新しく入ったアドレスについても同じ処理を1回繰り返した（2段目）。芯と1段目と2段目を合わせ、重複を除いたものが findsp2.l_spam.txt（8,132アドレス）である。つまり、8,132件のうち、手順1の条件（解除から3分以内など）で個別に確定したのは芯の278件であり、残りは、芯または1段目のアドレスから999 Piを超える送金を1回で受け取ったアドレスである。
  3. 途中版：findsp_resd_out.txt（7,967アドレス）は、それ以前のプログラム（findsp.py）の出力を整えたもので、8,132件の中に全部含まれている（差の165件は findsp2.l_spam.txt にだけある）。
  4. 物差しを下げた版：物差しを499 Piに下げたプログラム（findsp3.py）によるリスト（12,932アドレス）も当時作られたが、本レポートの解析対象には含めていない。対象は findsp2.l_spam.txt の8,132アドレスのみである。
  5. 一致の確認（2026年11月）：当時のアーカイブに保存されていた findsp2.l_spam.txt は、本レポートが使うリストと1件の差もなく一致した。また、封鎖期間の全送金データで広がりの手順を再現したところ12,228アドレスが得られ、8,132アドレスはその中に全部含まれていた（再現側が多いのは、対象とする期間が当時より長いためである）。

作成時のプログラムと出力ファイルは、本リポジトリの archive フォルダに保存した。
