# Pi Network 三段目追跡（third-hop）サマリー

作成: 2026-10-31 / 解析: モコ (Muse) / モデル: Muse Spark 1.3
方法: 二段目追跡で判明した次段宛先 GDGII3Q2US4L… について、Pi Mainnet Horizon APIで全期間の payments を取得し、ネイティブPiのみ集計（二段目と同一手法）。現在残高は /accounts 取得。
注意: 取引所ラベル（OKX / Gate.io関連 / Bitget / MEXC）は第三者の調査報告に基づくもので、取引所公式の発表ではない。チェーン上の資金移動は同一グループの可能性を示すもので、人物の特定や盗みの断定にはならない。
実行結果: HTTP 429 なし、完了、300,000件の上限到達なし（取得レコード 3,472件）。
取得上の注記: このアカウントの payments ページでは urllib が繰り返し IncompleteRead（応答の途中切断）を起こした（limit=25 でも発生、2026-10-31確認）。curl と requests では同一ページを正常取得できたため、third_hop.py のHTTP取得のみ requests に切り替えた。API・エンドポイント・集計方法は二段目と同一。

## 整合性チェック（入金 − 送金 と現在残高の差）
payments は送金/入金の操作のみを対象とするため、取引手数料や claimable balance 等の対象外操作があると残高と一致しない。差を隠さず記録する。
- GDGII3Q2US4L… : 残高 − (入金−送金) = -9.19 Pi
- 差は約9 Piのみで、手数料の累積として整合する範囲。10,000 Pi を超える乖離はないため、claimable balance 等の /operations 追加確認は不要だった（実施なし）。
- 分類合計の検証: 送金は 取引所 260,627,120 + リスト復帰 9.95 + 二段目セット 0 + その他外部 32,869,972 = 293,497,102 Pi で送金総額と一致。入金も リスト 0 + 二段目セット 5,087,483 + その他外部 299,932,459 = 305,019,942 Pi で入金総額と一致（いずれも丸め誤差 0.001 Pi 未満）。
